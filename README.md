Welcome to Simply Quests!

This mod requires NeoForge version 26.1.0.19-beta or higher!

To install, place the Simply Quests v0.1.0.jar file directly into your mods folder.

At the very start, there are no chapters or groups in the side bar.
You cannot add any quests without having a chapter open to add quests to. Create a new Chapter, then you can start adding quests!

Controls:

You can open up the quest screen by clicking o (default) or by clicking on the quest book in your inventory. 
This quest book can be moved wherever you want it.

Quest Nodes, Tasks, Rewards, Chapters, Groups, Images, Text, can all be moved by either middle mouse clicking or right click + selecting move.
This will show a shadow of the object that follows your mouse around. When you Left click to place the object, the original item will then move to that location.

Creating a Group/Chapter
When edit mode is enabled, if you bring up the Side Bar, you can see a + button at the top right corner of the Side Bar. This allows you to create Groups or Standalone Chapters.
When there is an existing Group, there will be + buttons to the right of each Group to add Chapters directly into the Group.

Chapter icons can be changed by Right Clicking on the Chapter and clicking Edit Icon.

Creating a Quest:
While a Chapter is selected, right click within the Quest Canvas to bring up a Context Menu. Here you should see; Create Quest, Add Text, Add Image
Clicking on Create Quest will bring up the Quest Editor. Here you can set various options. Task/Reward creation is handled within the Quest Details window separately.

Adding Images:
You can add Images directly onto the Chapter Canvas by opening up the context menu and selecting Add Image. This will bring up a File Explorer that lets you select your image file.
This file has to be a .png image and will give you an error message if you try to add anything that isn't a .png file.

Adding Text:
Like Quests and Images, bring up the Context Menu and select Add Text. This will bring up a little editor that will allow you to adjust what it says, the size, and the color.
Text can be edited after creation at any point by right clicking the text and clicking edit text.
